# Histórico e atribuições do Motion Laucher
A base Android nativa deriva do projeto [wiiguy/lightweight_androidtv_launcher](https://github.com/wiiguy/lightweight_androidtv_launcher), licença **GPL-3.0-or-later**, cujos avisos e código-fonte devem ser preservados.

A primeira variante usada no HY300por recebeu o nome Linkou Home e posteriormente CreativeScreen. O nome oficial atual é **Motion Laucher**. A Linkou foi apenas uma ferramenta de desenvolvimento externa, não uma dependência do app.

O package id `pro.creativezone.hy300launcher` foi mantido para não romper o caminho de atualização no mesmo dispositivo. A versão web gamer em `apps/tv-preview` ainda não foi portada ao Android nativo; o APK atual é apenas a base leve já testada.

Chaves de assinatura de release NÃO são armazenadas no GitHub e devem ser preservadas fora da VPS antes de qualquer limpeza de material criptográfico.
